# Goal

I have a shortlist of 8 holiday destinations that already passed screening.
For each one, build a sealed decision pack so I can rank them myself later,
then adversarially fact-check every pack.

Decision pack rules:

- One researcher per destination. Each researcher is sealed: it knows
  nothing about the other candidates and must not compare or rank against
  them. Opinionated is good; hedged mush is failure.
- Every pack must contain: primary base plus 2–4 alternative sleep options,
  an explicit end-to-end travel chain with a change count, realistic
  door-to-door hours for a family with young children, about 3 named
  family-capable stays with rough price signals, a cost band, scores on the
  fixed 0–10 dimensions given with the run, exactly 3 load-bearing claims,
  and sources for everything. Web verification required; memory-only claims
  are not acceptable.
- Full packs are large. Keep the complete packs in a durable artifact and
  hand the coordinator compact cards (one line of scores and identifiers per
  destination) plus the artifact reference.

Fact-check rules:

- One adversarial checker per pack. Its job is to REFUTE the 3 load-bearing
  claims with independent searching, not to rubber-stamp. Each claim gets
  CONFIRMED, CONTRADICTED, or UNVERIFIABLE-ONLINE with a note and source.
- If a checker fails to run or returns garbage, the pack's claims are marked
  UNVERIFIABLE-ONLINE across the board. A missing check is never treated as
  confirmation.

Final output: the 8 packs (artifact reference), per-pack fact-check results,
and a coverage summary. No overall winner — ranking is mine.
